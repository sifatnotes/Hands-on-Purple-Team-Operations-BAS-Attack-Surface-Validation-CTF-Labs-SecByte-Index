# Purple Team Operations, BAS & Attack Surface Validation CTF Labs

Welcome to the **Purple Team Operations, BAS & Attack Surface Validation CTF Lab Collection**. This repository serves as a structured, searchable catalog of practical cybersecurity labs hosted on Learn SecByte.

This collection focuses on collaborative security operations, **Breach & Attack Simulation (BAS)**, comprehensive **Attack Surface Validation**, threat mapping frameworks (**Cyber Kill Chain**, **MITRE ATT&CK Navigator**), and systematic **Detection Gap Analysis**.

## Learning Path

### Path A: Threat Mapper & Attack Surface Specialist
1. **Threat Modeling & Frameworks:** Start with [Threat Modeling Foundations](https://learn.secbyte.org/ctf/threat-modeling-foundations), [Cyber Kill Chain Mapping](https://learn.secbyte.org/ctf/cyber-kill-chain-mapping), and [Mapping the Battlefield: ATT&CK Navigator](https://learn.secbyte.org/ctf/mapping-the-battlefield-attck-navigator).
2. **Surface & Control Auditing:** Validate assets and security tools via [Attack Surface Validation](https://learn.secbyte.org/ctf/attack-surface-validation) and [Security Control Validation Mastery](https://learn.secbyte.org/ctf/security-control-validation-mastery).

### Path B: BAS Specialist & Detection Assessor
1. **Automated Simulation:** Learn simulation concepts through [Attack Simulation Basics](https://learn.secbyte.org/ctf/attack-simulation-basics) and [BAS Fundamentals](https://learn.secbyte.org/ctf/bas-fundamentals).
2. **Gap Analysis & Coverage:** Audit telemetry in [Gap Analysis Essentials](https://learn.secbyte.org/ctf/gap-analysis-essentials), [Detection Coverage Analysis](https://learn.secbyte.org/ctf/detection-coverage-analysis), and [Detection Validation Mastery](https://learn.secbyte.org/ctf/detection-validation-mastery).

### Path C: Purple Team Operational Leader
1. **Collaborative Execution:** Practice joint exercises in [Purple Team Operations: Collaborative Defense](https://learn.secbyte.org/ctf/purple-team-operations-collaborative-defense).
2. **Strategic Operations:** Complete the operational cycle with [Purple Team Strategy and Planning](https://learn.secbyte.org/ctf/purple-team-strategy-and-planning).
